# Seating Arrangement Generator – Examination Management System

## Overview
The **Seating Arrangement Generator** is a web-based application designed to simplify and automate the process of arranging students in examination halls. It helps generate seating plans based on room capacity, student details, branches, and examination requirements.

The application reduces manual work, saves time, and helps maintain an organized examination seating process.

## Features
- **Student Data Management:** Add student details manually or import them using Excel files.
- **Excel and ZIP Upload:** Upload branch-wise student data.
- **Room Configuration:** Select examination rooms and configure room capacity and bench arrangements.
- **Automatic Seating Arrangement:** Generate seating plans based on the available rooms and student details.
- **Detained Student Exclusion:** Exclude detained students from the seating arrangement.
- **Supplementary Examination Support:** Handle supplementary student lists.
- **Seating Plan Management:** Review and modify seating arrangements using drag-and-drop functionality.
- **Attendance Sheets:** Generate attendance sheets for examination rooms.
- **Consolidation Report:** Generate a consolidated seating report.
- **Invigilator Sign Sheets:** Prepare sign sheets for invigilators.
- **Question Paper List:** Generate and export question paper lists.
- **Export and Print:** Download reports in PDF or Excel format and print them.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- SheetJS (XLSX)
- JSZip
- Browser Print Functionality

## How to Use
1. Open the application in a web browser.
2. Sign in, create an account, or continue as a guest.
3. Enter the examination details.
4. Select examination rooms.
5. Configure room capacity and bench arrangements.
6. Add student details manually or upload Excel/ZIP files.
7. Review and validate the student information.
8. Generate the seating arrangement.
9. Review or modify the generated seating plan.
10. Generate attendance sheets and other examination reports.
11. Export or print the required documents.
