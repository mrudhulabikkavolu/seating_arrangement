Mode 1 — Same Year · 2 Different Branches

Mode 2 — Same Year · 3 Different Branches
Left ≠ Middle ≠ Right · All three slots are different branches · Fixed pattern — same order in every column

Mode 3 — Two Different Academic Years (Dual ZIP / Multi-Group)
Enables independent branch configuration for two separate admitted years. Pattern alternates: Col1 = Yr1|Yr2|Yr1 → Col2 = Yr2|Yr1|Yr2 → Col3 = Yr1|Yr2|Yr1 and so on.
